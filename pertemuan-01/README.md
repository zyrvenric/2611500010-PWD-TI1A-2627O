1. Konsep Dasar Pemrograman Web
pemrograman web itu proses membuat website atau aplikasi yang dapat diakses melalui internet menggunakan browser atau sejenisnya
2. Arsitektur Klien-Peladen
client meminta data pada server, lalu server memproses dan mengirimkan hasil kembali kepada client
3. HTTP Request dan Response
request adalah permintaan dari client ke server, sedangkan response adalah jawaban dari server kepada client
4. HTML, CSS, JavaScript, PHP, MySQL
HTML itu struktur, CSS untuk tampilan, JavaScript untuk interaksi, PHP untuk proses server, dan MySQL untuk database
5. Hubungan Antarteknologi
HTML, CSS, dan JavaScript digunakan di sisi client, sedangkan PHP memproses data di server dan MySQL menyimpan data. HTTP menghubungkan client dengan server
